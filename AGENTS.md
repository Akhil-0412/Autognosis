# Autognosis Repository Guidelines

## Coding Conventions
- **Frontend**: TanStack Start (TypeScript, React 19, Tailwind CSS v4 tokens).
- **Backend**: FastAPI (Python 3.12, Uvicorn, Pydantic v2).
- **Styles**: Defined in `src/styles.css`. Maintain cyberpunk HUD aesthetic (`plasma`, `ion`, `void`, `deep`, `surface`).
- **Dependencies**: Use `npm install` for frontend packages and `uv run` for Python dependencies.
